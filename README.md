# Macroeconomic Model Database

Welcome to the Macroeconomic Model Database! This repository serves as a comprehensive collection of macroeconomic models used in research, policy analysis, and education. Models are organized by category to facilitate easy navigation and discovery.

## 📚 Repository Structure

This database organizes macroeconomic models into the following categories:

### [Benchmark Models](./Benchmark%20Models)
Core macroeconomic frameworks that serve as foundational tools for analysis.
- **Examples**: RBC models, Basic New Keynesian DSGE models, Solow Growth Model
- **Model Codes**: `BM-001` through `BM-099`

### [Financial Frictions](./Financial%20Frictions)
Models incorporating financial market imperfections, credit constraints, and banking sectors.
- **Examples**: Bernanke-Gertler-Gilchrist model, Kiyotaki-Moore credit cycles
- **Model Codes**: `FF-001` through `FF-099`

### [Fiscal Policy](./Fiscal%20Policy)
Models focused on government spending, taxation, and fiscal multipliers.
- **Examples**: Tax policy models, Government spending models, Debt sustainability models
- **Model Codes**: `FP-001` through `FP-099`

### [Labor Markets](./Labor%20Markets)
Models emphasizing employment dynamics, wage formation, and labor market frictions.
- **Examples**: Search and matching models, Wage rigidity models, Human capital models
- **Model Codes**: `LM-001` through `LM-099`

### [Open Economy](./Open%20Economy)
Models analyzing international trade, exchange rates, and global economic interactions.
- **Examples**: Mundell-Fleming model, Two-country DSGE models, Trade models
- **Model Codes**: `OE-001` through `OE-099`

### [Unconventional Policy](./Unconventional%20Policy)
Models exploring non-standard monetary and fiscal interventions.
- **Examples**: Zero lower bound models, Quantitative easing models, Forward guidance models
- **Model Codes**: `UP-001` through `UP-099`

### [Specialized Sectors](./Specialized%20Sectors)
Models focusing on specific sectors or industries within the economy.
- **Examples**: Housing market models, Energy sector models, Healthcare models
- **Model Codes**: `SS-001` through `SS-099`

## 🚀 Getting Started

### Contributing a Model

1. **Choose the appropriate category** for your model
2. **Assign a model code** following the category prefix (e.g., `BM-001` for Benchmark Models)
3. **Create a folder** within the category directory with your model code and name
4. **Include the following files**:
   - `README.md` - Model description, equations, and documentation
   - Source code files (`.mod`, `.m`, `.py`, `.jl`, etc.)
   - Calibration files and parameters
   - Example outputs or plots
5. **Update the Model Index** in this README with your model's information

### Model Documentation Template

Each model should include:
- **Model Name and Code**
- **Author(s)** and References
- **Overview**: Brief description of the model's purpose
- **Key Features**: Main characteristics and innovations
- **Equations**: Core model equations
- **Parameters**: Calibration and parameter values
- **Usage**: Instructions for running the model
- **Results**: Expected outputs and interpretations
